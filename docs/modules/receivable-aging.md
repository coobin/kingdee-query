# 应收账龄

## 模块定义

| 项目 | 内容 |
| --- | --- |
| 工具 ID | `receivable_aging` |
| 查询类型 | `receivable_aging`，按应收单明细和开票核销记录计算 |
| 结果粒度 | 一个仍有应收未收款余额的销售子项目一行 |
| 默认账龄 | 超过 180 天 |
| 统计日 | 服务端按 `Asia/Shanghai` 业务时区计算当天 |
| 默认排序 | 应收未收款金额降序，其次应收未开票金额降序、应收超期天数降序 |

## 数据来源

| 来源用途 | 金蝶表单 | 关键字段 |
| --- | --- | --- |
| 超期应收候选和应收日期 | `AR_RECEIVABLE` | `FBillNo`、`FDate`、`FALLAMOUNTFOR`、`FRECEIVEAMOUNT`、`FNORECEIVEAMOUNT`、销售子项目和客户 |
| 应收未开票辅助维度 | `AR_BILLINGMATCHRECORD` | 来源/目标单据号、目标分录内码、单据类型、本次和累计开票核销金额 |
| 收款条件 | `PARA_SaleSubProject` | `FBillNo`、`FRecConditionStr` |

本模块不按收款单单据头的销售子项目字段直接汇总回款。应收单的 `FRECEIVEAMOUNT`/`FNORECEIVEAMOUNT` 是收款已经分配到应收单后的状态，因此能够避免“收款单抬头项目”和实际核销目标应收单不一致时的串项目问题。

## 查询参数

| 外部参数 | 规则 |
| --- | --- |
| `minimumDays` | 整数 1–3650，默认 180；截止日 = 统计日 - 天数 |
| `customerName` | 按应收单客户名称包含匹配，可选 |
| `subprojectNumber` | 按应收单销售子项目编码包含匹配，可选；兼容参数 `projectNumber` |
| `limit` | 只限制最终返回的销售子项目行数，不限制后台分页读取 |

候选应收单固定要求：已审核、未作废、应收金额不为 0、未收金额大于 0，并且 `FDate < 统计日 - minimumDays`。服务端会再次按日期和余额过滤，避免远程过滤条件被忽略时把非超期或已结清明细纳入结果。

## 结果字段字典

| 返回字段 | 计算/来源 | 业务含义 |
| --- | --- | --- |
| 客户 | 应收单客户去重拼接 | 销售子项目关联客户 |
| 销售子项目编码 | 应收单销售子项目编码 | 汇总主键 |
| 销售子项目名称 | 应收单销售子项目名称去重拼接 | 可读名称 |
| 应收账龄日期 | 该销售子项目最早仍有未收款余额的应收单日期 | 应收账龄起算日期 |
| 应收超期天数 | 统计日 - 应收账龄日期 | 自然日账龄 |
| 应收单数 | 应收单号去重计数 | 本次超期应收范围内的应收单数 |
| 应收金额 | 超期应收分录 `FRECEIVEAMOUNT + FNORECEIVEAMOUNT` 汇总 | 本次超期应收范围的分录级应收金额；`FALLAMOUNTFOR` 只用于候选过滤和缺少分录金额时的兜底，不能在多分录应收单上直接累加 |
| 应收已收款金额 | `应收金额 - 应收未收款金额` | 已分配到这些应收单的回款，不是该项目全部收款单金额 |
| 应收未收款金额 | 超期应收明细 `FNORECEIVEAMOUNT` 汇总 | 按应收单维度的核心超期风险金额 |
| 应收未开票金额 | `max(应收金额 - 开票核销金额, 0)` | 已形成应收但尚未被销售发票匹配覆盖的金额 |
| 回款状态 | 根据应收已收款金额判断 | 完全未回款或部分回款未结清 |
| 收款条件 | `PARA_SaleSubProject.FRecConditionStr` | 销售子项目收款条件 |

## 计算口径

1. 先以应收单日期和未收金额筛出超期候选，只保留仍有余额的应收明细；不要求 `FIVALLAMOUNTFOR > 0`，所以已经做应收但尚未开票的明细也会进入结果。
2. 以应收单明细为金额粒度；同一应收分录重复返回时按应收单号和分录内码去重，避免分页或关联展开造成金额重复。
3. `应收未收款金额`是本模块的主要风险口径，直接来自应收明细未收余额；收款已核销到应收的部分通过应收余额体现。
4. `应收未开票金额`只作为辅助分析维度，不从应收未收款金额中扣除，也不把它当作已回款。这样可以同时回答“钱还没收回来多少”和“其中有多少还没有开票”。
5. `overdue_receivables` 仍然保留原有“发票账龄”的独立口径。两个工具是互补视图，不能直接把两边的金额相加，因为同一笔余额可能同时出现在两种账龄范围内。

核心关系为：

```text
应收金额 = 超期应收分录 FRECEIVEAMOUNT + FNORECEIVEAMOUNT 汇总
应收未收款金额 = 超期应收分录 FNORECEIVEAMOUNT 汇总
应收已收款金额 = 应收金额 - 应收未收款金额
应收未开票金额 = max(应收金额 - 应收开票核销金额, 0)
```

## 统计信息与限制

`statistics` 包含统计日、账龄天数、销售子项目数、应收单数、客户数、应收金额、应收已收款金额、应收未收款金额、应收未开票金额、完全未回款和部分回款未结清的数量及金额。模块用于应收风险筛选，不替代财务对收款单、退款单和核销记录的最终对账。
