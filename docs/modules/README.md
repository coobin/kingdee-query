# 查询模块说明

本目录记录 Query Hub 当前登记的业务查询模块。文档只描述业务用途、查询条件、结果口径、权限和限制，不记录真实账号、密码、密钥、域名、IP、客户名称、项目编号、金额或业务单据内容。

## 模块目录

| 模块 | 说明 |
| --- | --- |
| [即时库存](inventory.md) | 按物料、仓库和库存组织查看库存 |
| [销售订单](sales-orders.md) | 按单据、客户或日期查询销售订单 |
| [超期未回款](overdue-receivables.md) | 按销售子项目和开票日期核对长期未结清应收 |
| [采购订单](purchase-orders.md) | 按单据、供应商或日期查询采购订单 |
| [费用报销](expense-claims.md) | 查询本人或授权范围内的报销单 |
| [审批进度](workflow-progress.md) | 查询指定单据的当前审批节点和历史 |

## 统一规则

- 页面使用结构化条件；不接受任意 SQL、金蝶过滤表达式、表单编号或返回字段作为用户输入。
- 服务端再次检查模块、字段、筛选范围和返回行数；填写条件不会扩大金蝶权限。
- 查询使用当前登录身份访问金蝶，最终结果仍受金蝶业务权限和组织权限约束。
- 查询结果会记录审计信息，但文档、测试数据和示例不得包含真实业务数据。
- 修改模块字段或金额口径时，必须同步更新 `config/query-catalog.json`、对应查询逻辑、测试和本目录文档。

## 敏感信息检查

提交前请确认文档没有出现：

- 账号、密码、Passkey、API Key、应用密钥或代理共享密钥；
- 生产域名、内网地址、服务器地址、数据库连接信息；
- 真实客户、员工、销售子项目、合同、单据编号或金额；
- 从金蝶导出的原始行、权限清单、审计日志或业务附件。
