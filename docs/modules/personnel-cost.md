# 人员成本

## 模块定义

| 项目 | 内容 |
| --- | --- |
| 工具 ID | `personnel_cost` |
| 工资单表单 | `PARA_PM_PayrollBill` |
| 报销单表单 | `ER_ExpReimbursement` |
| 数据粒度 | 一名员工在所选期间汇总为一行 |
| 计算公式 | `人员成本 = 实发工资 + 非专项核定报销金额` |
| 默认期间 | 上一个完整自然月 |
| 最大期间 | 366 天 |

## 数据来源与字段字典

### 工资单

| 用途 | 金蝶字段 | 说明 |
| --- | --- | --- |
| 工资单号 | `FBillNo` | 用于单据计数，不公开展示 |
| 工资日期 | `FDate` | 按所选开始、结束日期纳入 |
| 员工编号 | `FEmpInfoId.FNumber` | 人员归集主键 |
| 姓名 | `FEmpInfoId.FName` | 展示名称 |
| 所属部门 | `FStaffDeptId.FName` | 优先作为人员部门 |
| 币别 | `FCurrencyId.FNumber` | 用于阻止不同币别直接相加，不公开展示 |
| 实发工资 | `FFinalPayAmt` | 工资成本金额 |
| 审核状态 | `FDocumentStatus` | 固定只纳入 `C`（已审核） |

### 费用报销单

| 用途 | 金蝶字段 | 说明 |
| --- | --- | --- |
| 报销单号 | `FBillNo` | 用于单据计数，不公开展示 |
| 申请日期 | `FDate` | 按所选开始、结束日期纳入 |
| 员工编号 | `FProposerID.FNumber` | 与工资单员工编号关联 |
| 姓名 | `FProposerID.FName` | 工资单缺失时作为展示名称 |
| 申请部门 | `FRequestDeptID.FName` | 工资单部门缺失时作为部门 |
| 币别 | `FCurrencyID.FNumber` | 用于阻止不同币别直接相加，不公开展示 |
| 报销类型 | `F_PARA_ExType` | 分录字段；固定排除 `A`（专项） |
| 核定报销金额 | `FExpSubmitAmount` | 分录核定金额；只汇总非专项分录 |
| 审核状态 | `FDocumentStatus` | 固定只纳入 `C`（已审核） |

## 公开结果

| 展示字段 | 计算或来源 |
| --- | --- |
| 员工编号 | 工资单员工编号；仅有报销时取申请人员工编号 |
| 姓名 | 工资单姓名；仅有报销时取申请人姓名 |
| 所属部门 | 优先取工资单所属部门，否则取报销申请部门 |
| 实发工资 | 期间内该员工 `FFinalPayAmt` 合计 |
| 报销金额 | 期间内该员工非专项分录 `FExpSubmitAmount` 合计 |
| 人员成本 | 实发工资加报销金额 |
| 工资单数 | 参与计算的已审核工资单数量 |
| 报销单数 | 参与计算的已审核费用报销单数量 |
| 数据构成 | 工资 + 报销、仅工资或仅报销 |

汇总区同时展示人员成本、实发工资、非专项核定报销金额、单据数量和三类数据构成人数。结果按人员成本从高到低排列，并可在页面再次排序或导出 CSV。

## 查询参数

| 外部参数 | 页面 | 匹配方式 | 工资单字段 | 报销单字段 |
| --- | --- | --- | --- | --- |
| `dateFrom` | 必填 | 大于等于 | `FDate` | `FDate` |
| `dateTo` | 必填 | 小于结束日下一天 | `FDate` | `FDate` |
| `employeeNumber` | 可选 | 精确 | `FEmpInfoId.FNumber` | `FProposerID.FNumber` |
| `employeeName` | 可选 | 包含 | `FEmpInfoId.FName` | `FProposerID.FName` |
| `departmentName` | 可选 | 包含 | `FStaffDeptId.FName` | `FRequestDeptID.FName` |

## 完整性、权限和限制

- 工资单和报销单分别使用稳定排序、`TopRowCount: 0` 和分页读取，所选期间内不套用页面普通 100 行上限；`truncated=false`、`partial=false` 才表示两端扫描完成。
- 查询范围必须同时提供开始、结束日期，且最多 366 天，避免无边界读取工资和报销历史。
- 归集以员工编号为主，不以姓名作为首选关联键。当前生产样本中工资单员工编号与 HR 工号一致，所抽取期间的报销申请人员工编号均能匹配工资单员工编号；未来导入规则变化时需重新核对。
- 仅有报销、期间内没有工资单的人员仍会展示为“仅报销”，避免漏掉已发生的成本；汇总区会单独标记人数。
- 报销按分录统计，`F_PARA_ExType='A'`（专项）的分录固定排除；同一张报销单同时包含专项和非专项时，只汇总非专项分录，报销单数按单据号去重。
- 工资与报销必须是同一币别；发现多个币别时服务端拒绝相加并提示缩小范围或先统一币别。当前模块不做汇率换算。
- 模块带有 `restrictedByDefault`，名单为空时仅超级管理员可见。普通用户即使知道工具 ID，也会被服务端拒绝；加入名单只会收紧 Query Hub 入口，最终查询仍受该用户在金蝶中的工资单、报销单和数据范围权限约束。
- 审计日志记录查询人、筛选条件、返回人数、完整性和耗时，不记录返回的工资或报销金额明细。
