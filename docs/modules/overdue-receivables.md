# 超期未回款

## 用途

按销售子项目汇总已开票后超过指定天数、且应收仍未结清的风险金额。默认账龄阈值为 180 天。

## 查询条件

- 超过天数：整数，范围为 1 到 3650，默认 180；
- 客户名称：可选模糊匹配；
- 销售子项目编码：可选模糊匹配。

起始日：以销售发票的开票日期开始计算。系统使用业务时区计算查询日，并用“开票日期早于查询日减去阈值”的条件筛选超期发票。

## 当前计算口径

1. 以已审核、未作废、开票日期早于账龄截止日的销售发票作为入口，按销售子项目汇总，同一子项目只输出一行。
2. 从销售发票中取得该子项目的开票日期，并以最早开票日期作为该子项目的起算日期。
3. 再关联已审核、未作废的应收明细，计算应收未回款金额和已核销金额；没有应收单的发票不会被静默丢弃。
4. 再关联已审核、未作废的收款单和退款单，计算实际回款净额和收款未核销金额。
5. 已结清且没有未生成应收金额的子项目不进入风险结果；没有销售子项目编码或找不到开票日期的明细会被排除并在统计信息中提示。

## 输出

- 客户；
- 销售子项目编码、销售子项目名称；
- 开票日期、超期天数、超期发票数；
- 应收单数；
- 开票金额；
- 实际回款净额；
- 未核销金额；
- 未生成应收金额；
- 未回款金额；
- 回款状态；
- 销售员。

## 金额口径特别说明

金额字段分别代表不同事实，不能互相替代：

```text
实际回款净额 = 有效收款单合计 - 有效退款单合计
```

```text
未核销金额 = max(实际回款净额 - 应收已核销金额, 0)
```

“未回款金额”仍以应收单未收余额为风险口径；“实际回款净额”来自有效收款单减有效退款单；“未生成应收金额”表示发票金额没有对应应收金额，不能当作已回款。

## 发票无应收单的限制

只有销售发票、没有应收单的子项目会进入结果，并显示“未生成应收金额”和“发票未生成应收”状态。该金额不能直接认定为已回款或应收未回款。

## 权限和限制

查询结果受当前金蝶用户权限约束，扫描和返回数量受服务端上限约束。达到上限时结果会标记为可能不完整。该模块用于风险筛选，不替代财务对收款单、退款单、应收单和核销记录的最终对账。
