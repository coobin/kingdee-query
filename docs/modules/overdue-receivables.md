# 超期未回款

## 用途

按销售子项目汇总已开票后超过指定天数、且应收仍未结清的风险金额。默认账龄阈值为 180 天。

## 查询条件

- 超过天数：整数，范围为 1 到 3650，默认 180；
- 客户名称：可选模糊匹配；
- 销售子项目编码：可选模糊匹配。

起始日：以销售子项目第一张超期发票的开票日期计算。系统使用业务时区计算查询日，并用“开票日期早于查询日减去阈值”的条件筛选超期发票。

## 当前计算口径

1. 以已审核、未作废、开票日期早于账龄截止日的蓝字和红字销售发票作为入口，按销售子项目汇总，同一子项目只输出一行。
2. 从上述超期发票中取得该子项目的开票日期，并以最早一张超期发票的开票日期作为账龄起算日期；所有金额字段都只汇总超期发票范围，不包含该子项目的未超期发票。红字发票会先与同一子项目的蓝字发票净额化，已被红字冲销的旧蓝字发票不再重复计入未生成应收金额。
3. 再关联已审核、未作废的应收明细，计算超期发票范围内的应收未收款金额；没有应收单的发票不会被静默丢弃。
4. 收款金额按发票—应收匹配结果分摊到超期发票范围，计算已收款金额和收款未核销金额，不直接把该子项目全部收款单金额计入超期结果。
5. 从已审核、未作废的销售订单取得该销售子项目的收款条件；同一子项目存在多个条件时全部显示。
6. 已结清且没有未生成应收金额的子项目不进入风险结果；没有销售子项目编码或找不到开票日期的明细会被排除并在统计信息中提示。

## 输出

- 客户；
- 销售子项目编码、销售子项目名称；
- 收款条件；
- 最早超期发票的开票日期、超期天数、超期发票数；
- 应收单数；
- 开票金额；
- 已收款金额；
- 收款未核销金额；
- 未生成应收金额；
- 应收未收款金额；
- 未回款金额；
- 回款状态；

## 金额口径特别说明

金额字段分别代表不同事实，不能互相替代：

```text
已收款金额 = 超期发票金额 - 应收未收款金额 - 未生成应收金额
```

```text
收款未核销金额 = 超期范围内已收款但尚未匹配应收的金额
```

```text
未回款金额 = max(开票金额 - 已收款金额, 0)
             = 应收未收款金额 + 未生成应收金额
```

“应收未收款金额”表示超期范围内已形成应收但仍未收取的金额；“未生成应收金额”表示红蓝字净额化后仍没有对应应收的金额；“已收款金额”按超期发票与应收匹配后的剩余金额计算；“未回款金额”是超期发票金额减超期已收款金额。这样所有字段处于同一超期范围，并满足“未回款金额 = 应收未收款金额 + 未生成应收金额”。

收款条件来自销售订单的收款条件字段；没有匹配到销售订单或订单未设置收款条件时，该列为空。

## 发票无应收单的限制

只有销售发票、没有应收单的子项目会进入结果，并显示“未生成应收金额”和“完全未形成应收”状态；已经形成部分应收但仍有差额的项目显示“未完全形成应收”。未生成应收金额不能直接认定为已回款或应收未收款。

## 权限和限制

查询结果受当前金蝶用户权限约束。模块会先分页读取符合账龄条件的发票，再按销售子项目分批，并把每批发票、应收、收款和退款明细分页读取到最后一页；页面显示行数仍受返回条数控制。该模块用于风险筛选，不替代财务对收款单、退款单、应收单和核销记录的最终对账。
