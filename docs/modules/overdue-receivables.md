# 超期未回款

## 用途

按销售子项目汇总已开票后超过指定天数、且应收仍未结清的风险金额。默认账龄阈值为 180 天。

## 查询条件

- 超过天数：整数，范围为 1 到 3650，默认 180；
- 客户名称：可选模糊匹配；
- 销售子项目编码：可选模糊匹配。

起始日：以销售发票的开票日期开始计算。系统使用业务时区计算查询日，并用“开票日期早于查询日减去阈值”的条件筛选超期发票。

## 当前计算口径

1. 从已审核、未作废、已开票且仍有未收金额的应收明细中取得销售子项目。
2. 从销售发票中取得该子项目的开票日期，并以最早开票日期作为该子项目的起算日期。
3. 按销售子项目汇总开票金额和未收金额；同一子项目只输出一行。
4. 已结清的应收明细不进入风险金额；没有销售子项目编码或找不到开票日期的明细会被排除并在统计信息中提示。

## 输出

- 客户；
- 销售子项目编码、销售子项目名称；
- 开票日期、超期天数、超期发票数；
- 应收单数；
- 开票金额；
- 已回款金额；
- 未回款金额；
- 回款状态；
- 销售员。

## 金额口径特别说明

当前代码中的“已回款金额”是由“开票金额减未回款金额”推导出的应收已收/已核销口径，不是收款单实际到账金额。它不能替代以下净额：

```text
实际回款净额 = 收款单合计 - 退款单合计 - 其他有效冲销
```

如果需要展示真实现金回款，应单独接入收款单、退款单和核销关系，并同时展示“实际回款净额”和“收款未核销金额”。在完成该改造前，不应把当前“已回款金额”用于现金流或到账分析。

## 发票无应收单的限制

当前模块以应收明细作为风险候选，再使用销售发票补充开票日期。因此只有销售发票、没有应收单的子项目不会自动进入当前结果。后续若要覆盖这种情况，应改为以销售发票为主表，并单独输出“发票未生成应收/未核销发票金额”；该金额不能直接认定为已回款或未回款。

## 权限和限制

查询结果受当前金蝶用户权限约束，扫描和返回数量受服务端上限约束。达到上限时结果会标记为可能不完整。该模块用于风险筛选，不替代财务对收款单、退款单、应收单和核销记录的最终对账。
