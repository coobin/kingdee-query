# 即时库存

## 用途

查询物料在仓库和库存组织中的当前库存数量，并在有批次管理时显示批号、生产日期和有效期。

## 查询条件

页面要求填写物料编码。服务端目录还允许以下白名单条件：

- 物料编码或物料名称；
- 仓库编码或仓库名称；
- 库存组织编码；
- 批号。

至少提供一个有效条件，避免无范围扫描。空条件、未登记条件和任意过滤表达式都会被拒绝或忽略。

## 输出

- 库存组织编码、库存组织；
- 物料编码、物料名称；
- 仓库编码、仓库；
- 批号；
- 基本库存数量、辅助库存数量；
- 生产日期、有效期至。

## 权限和限制

查询以当前金蝶用户身份执行，库存组织、仓库和物料数据由金蝶权限控制。数量是金蝶即时库存查询返回值，不代表锁库量、可用量或未来供应量，除非金蝶字段明确提供这些口径。
