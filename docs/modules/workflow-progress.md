# 审批进度

## 模块定义

| 项目 | 内容 |
| --- | --- |
| 工具 ID | `workflow_progress` |
| 金蝶表单 | 不使用标准 `ExecuteBillQuery`；调用部署配置的自定义只读 WebAPI |
| 数据粒度 | 当前登录用户发起的在审流程；可选按单据编号或表单号缩小到一张单据 |
| 启用条件 | 配置 `KINGDEE_WORKFLOW_METHOD` |
| 页面入口 | “我发起的流程”页签；单据编号可留空 |

## 请求数据字典

| 外部参数 | 传给自定义接口的字段 | 类型 | 说明 |
| --- | --- | --- | --- |
| `scope` | `Scope` | 固定文本 | 服务端固定传 `Mine`，只查询当前金蝶登录人的发起流程 |
| `formId` | `FormId` | 文本 | 可选，业务单据类型标识 |
| `billNumber` | `Number` | 文本 | 可选，指定业务单据编号 |

服务端只调用环境配置中的方法名，并把 `{Scope:"Mine", FormId?, Number?}` 作为 JSON 参数传入。发起人不能由调用方提交，必须由金蝶 WebAPI 当前登录上下文确定。调用方不能提交自定义 WebAPI 方法名、SQL 或任意额外参数。

## 输出数据

响应包含：

- `query.scope`、`query.formId`、`query.billNumber`：本次查询条件；
- `columns`、`rows`：单据编号、表单、流程名称、当前节点、当前处理人、节点到达时间、发起时间、状态；
- `truncated`：自定义接口或查询台达到返回上限时为 `true`；
- `summary`：说明本人在审流程数量。

节点、处理人和时间来自金蝶工作流表；本模块只把已验证的只读字段转换为页面列，不执行审批操作。

## 权限、启用状态和限制

- 未配置 `KINGDEE_WORKFLOW_METHOD` 时，目录仍可展示该模块，但 `available=false`，实际查询会失败并提示尚未配置。
- 当前用户必须同时具备 Query Hub 模块权限、金蝶登录权限和部署侧自定义接口允许的业务权限。
- 这是只读查询，不会提交、撤回、转交、催办或修改审批流程。
- 上游接口必须按 `kingdee-webapi/WorkflowQuery.cs` 的结构返回；本模块不接受任意 SQL、任意 WebAPI 方法名或外部传入的发起人。
