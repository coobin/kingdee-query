# 审批进度

## 用途

查询指定业务单据当前所在审批节点和可用的历史审批信息，帮助业务人员定位流程进度。

## 查询条件

- 单据类型标识；
- 单据编号。

两项都必须填写。服务端只调用部署侧登记的只读审批进度接口，不接受用户直接传入 WebAPI 方法名、SQL 或任意参数。

## 输出

返回审批进度接口提供的当前节点、处理人和历史节点等结构化信息。由于不同账套的审批接口字段可能不同，页面保留服务端返回的结构，不把未知字段解释成固定业务状态。

## 权限和限制

该模块需要部署只读的自定义审批进度接口并在服务端配置方法。未配置时模块会显示为待配置，不执行查询。结果仍受当前金蝶用户权限和部署侧审批接口权限约束。
