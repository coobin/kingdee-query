# 费用报销

## 用途

查询费用报销单的单据、申请人、部门、组织、审核状态和金额，用于个人报销跟踪。

## 查询条件

- 单据编号；
- 申请人编码或申请人名称；
- 申请部门；
- 申请组织；
- 开始日期或结束日期；
- 审核状态；
- 可选的金额汇总。

页面默认填写本年度日期范围。服务端要求至少提供一个有效筛选条件。

## 输出

- 单据编号；
- 申请日期；
- 申请人；
- 申请部门；
- 申请组织；
- 审核状态；
- 单据总金额；
- 审核日期。

## 权限和限制

普通用户的查询始终强制绑定当前登录人的申请人字段，不能通过提交其他申请人条件绕过。配置为授权范围管理员的账号可按系统授权范围查询。金额汇总只对当前查询返回范围计算，并受最大扫描行数限制；达到上限时结果会标记为可能不完整。
