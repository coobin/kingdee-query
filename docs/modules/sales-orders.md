# 销售订单

## 用途

查询销售订单的业务日期、销售组织、客户、金额和状态，用于日常订单跟进和基础核对。

## 查询条件

页面至少要求填写一项条件：

- 单据编号；
- 客户名称；
- 开始日期或结束日期。

服务端白名单还支持客户编码、销售组织名称和创建人名称。日期按业务日期筛选，结束日期包含当天。

## 输出

- 单据编号；
- 业务日期；
- 销售组织；
- 客户；
- 审核状态；
- 关闭状态；
- 价税合计；
- 创建人。

## 权限和限制

结果受当前金蝶用户的数据权限约束。页面和导出结果不展示金蝶内码，也不展示客户编码。状态码由服务端转换为中文；未登记的状态显示为其他状态，不应据此推断具体业务含义。
