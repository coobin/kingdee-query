# 销售订单

## 模块定义

| 项目 | 内容 |
| --- | --- |
| 工具 ID | `sales_orders` |
| 金蝶表单 | `SAL_SaleOrder` |
| 数据粒度 | 销售订单单据头；当前目录字段均为单据头字段，业务上按一单一行理解 |
| 默认排序 | `FDate DESC,FBillNo DESC` |
| 页面入口 | 单据编号、客户名称、开始日期、结束日期至少填写一项 |

## 数据来源与字段字典

| 展示字段 | 类型 | 金蝶字段 | 说明 |
| --- | --- | --- | --- |
| 单据编号 | 文本 | `FBillNo` | 销售订单业务单号 |
| 业务日期 | 日期 | `FDate` | 销售订单业务日期 |
| 销售组织 | 文本 | `FSaleOrgId.FName` | 销售组织名称 |
| 客户 | 文本 | `FCustId.FName` | 客户名称；页面不展示客户编码 |
| 审核状态 | 枚举文本 | `FDocumentStatus` | `Z` 暂存、`A` 已创建、`B` 审核中、`C` 已审核、`D` 重新审核；未知值显示“其他状态” |
| 关闭状态 | 原始枚举 | `FCloseStatus` | 当前没有配置状态码中文映射，按金蝶返回值展示 |
| 价税合计 | 金额 | `FBillAllAmount` | 订单返回的价税合计；没有币别字段，不能跨币种直接合计 |
| 创建人 | 文本 | `FCreatorId.FName` | 创建人名称 |

## 查询参数

| 外部参数 | 页面 | 金蝶筛选字段 | 匹配方式 | 备注 |
| --- | --- | --- | --- | --- |
| `billNumber` | 是 | `FBillNo` | 精确 |  |
| `customerNumber` | 否 | `FCustId.FNumber` | 精确 | 结构化 API 可用 |
| `customerName` | 是 | `FCustId.FName` | 包含 |  |
| `organizationName` | 否 | `FSaleOrgId.FName` | 包含 |  |
| `creatorName` | 否 | `FCreatorId.FName` | 包含 |  |
| `dateFrom` | 是 | `FDate` | 大于等于 | 包含开始日 |
| `dateTo` | 是 | `FDate` | 小于结束日的下一天 | 包含结束日 |

服务端要求至少提供一个有效筛选条件。页面和导出不展示金蝶内码及客户编码。

## 口径、权限和限制

- 金额字段只代表销售订单的价税合计，不代表已开票、已收款、已出库或合同余额。
- 只有审核状态有当前目录内的中文映射；关闭状态和未知状态码不能据此推断具体业务含义。
- 结果受当前金蝶用户的数据权限、销售组织权限和 Query Hub 模块访问名单约束。
- 返回行数受 `limit` 和服务端 `KINGDEE_MAX_ROWS` 共同限制，达到上限时结果可能不完整。
